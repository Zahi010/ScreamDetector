# 12. PHASE I — PAIRED MODEL COMPARISON

Compare Candidate E1 and Candidate B on identical recordings.

Report:

- Recording-level prediction disagreements.
- Candidate E1 correct / Candidate B incorrect.
- Candidate B correct / Candidate E1 incorrect.
- Both correct.
- Both incorrect.

Use McNemar's test for paired binary outcomes where appropriate.

Use source-group cluster bootstrap confidence intervals for recall and FPR comparisons.

Resample source groups rather than individual recordings.

Use at least 2,000 bootstrap replicates if computationally practical.

Use a fixed random seed.

If positive and negative source groups must be sampled separately, use a documented stratified cluster bootstrap.

Report the resampling methodology and the number of independent source groups.

Do not claim superiority from small point-estimate differences without uncertainty analysis.

# 13. PHASE J — ORIGINAL FIVE ACCEPTANCE GATES

Preserve the original gates:

| Gate | Requirement |
|---|---:|
| Overall scream recall | ≥96% |
| Hard-negative FPR | ≤5% |
| Shouted-speech FPR | ≤15% |
| Short-scream recall | ≥90% |
| Computational P95 inference latency | ≤25 ms |

Evaluate all gates on the same independent cohort.

Use the frozen validation-selected thresholds.

Report point estimates, confidence intervals, and independent source-group counts.

A point estimate passing a gate does not automatically establish statistical confidence.

Do not mix results across models, thresholds, or cohorts.

A candidate passes only if all five gates are satisfied by that same candidate on that same cohort.

Passing all five makes the candidate eligible for separate research review only. It does not authorize production deployment.
