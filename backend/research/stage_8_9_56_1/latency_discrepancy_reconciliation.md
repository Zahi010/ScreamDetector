## 3. Forensic Analysis by Metric and Candidate

### 3.1 Candidate E1: 39.189 ms vs 56.802 ms vs 46.066 ms
- **39.189 ms (Stage 8.9.55):** Genuine measurement of subband extraction + model inference, but omitted phonation statistics extraction (~6.4 ms) and normalization. It was computed by adding two decoupled arrays.
- **56.802 ms (Stage 8.9.56):** Genuine measurement of the integrated sequential downstream pipeline, including normalization, phonation extraction, subband filtering, tensor formatting, and model inference.
- **46.066 ms (Stage 8.9.56.1):** Fresh clean-room benchmark using authentic audio from the cohort over 300 steady-state iterations. Confirms that Candidate E1 complete pipeline operates in the **46-57 ms** range, reliably failing the 25.0 ms target.
- **Table B Inconsistency:** In Stage 8.9.56 `acceptance_gate_reconciliation.md`, Table B cited 39.189 ms while Sections 1, 2.4, and 8 cited 56.802 ms. This is confirmed as a documentation copy-paste oversight where Table B was copied from Stage 8.9.55.

### 3.2 Candidate B: 39.694 ms vs 7.536 ms
- **39.694 ms (Stage 8.9.55 & Stage 8.9.56 Table B):** In Stage 8.9.55 `benchmark_latency.py`, the author computed `p95_b + p95_fe = 0.831 ms + 38.863 ms = 39.694 ms`. This was architecturally erroneous because Candidate B **never consumes subband filterbank features** (only YAMNet + phonation statistics). Furthermore, scalar addition of percentiles violates statistical theory.
- **7.536 ms (Stage 8.9.56.1):** When Candidate B's actual downstream pipeline is benchmarked (audio normalization + phonation statistics + tensor conversion + model inference + thresholding), its P95 is **7.536 ms**.
- **Audit Verdict for Candidate B:** Candidate B easily passes Gate 5 ($\le 25.0$ ms) under BOTH model-only (0.831 - 0.956 ms) and complete downstream pipeline (7.536 ms) interpretations.

### 3.3 Candidate B + Intervention D: 10.881 ms
- The complete downstream pipeline for Candidate B + Intervention D incorporates the 6-d phonation feature extraction, model inference, and the Intervention D acoustic modulation filter (`apply_intervention_d`).
- Measured P95 is **10.881 ms**.
- Candidate B + Intervention D passes Gate 5 ($\le 25.0$ ms) under both interpretations.
